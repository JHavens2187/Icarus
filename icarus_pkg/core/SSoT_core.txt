================================================================================
ICARUS v3.4 ARCHITECTURE SPECIFICATION: CORE MODULE (icarus_pkg/core/)
================================================================================
Purpose:
Provides all foundational data structures, Pydantic configuration schemas,
unit-safe FITS/catalog ingestion, Multi-Extension FITS I/O, exception handling,
logging, and non-destructive runtime debugging middleware. Zero optimization or
astrophysical assumptions live here; this layer guarantees data integrity.

--------------------------------------------------------------------------------
FILES TO IMPLEMENT IN THIS DIRECTORY
--------------------------------------------------------------------------------

1. config.py (Evolved from v3.3 datastructures.py)
   - Role: Pydantic v2 configuration validation and hierarchical override merger.
   - Key Specifications:
     * `FittingConfig`: Validates `cont_type` ("powerlaw_feii", "polynomial"),
       `continuum_degree` (0-3), `continuum_windows`, `feii_windows`,
       `priority_lines`, `snr_threshold` (default 3.0), narrow sigma bounds
       (`min_sigma = 30 km/s`, `max_sigma = 450 km/s`), broad sigma bounds
       (`min_sigma = 800 km/s`, `max_sigma = 8000 km/s`), and `doublet_tying`.
     * `SetupConfig`: Supports both a scalar `resolution` Quantity (e.g.,
       "300 km/s") AND a `dispersion_curve` filename (e.g.,
       "jwst_nirspec_prism_disp.fits") for wavelength-dependent R(lambda_obs).
     * `IcarusConfig.get_target_config(target)`: Deep-merges Globals -> Setup ->
       Target-specific overrides.
     * Uses `importlib.resources` to resolve relative paths to `data/` and
       `presets/` automatically.

2. containers.py (Extracted from v3.3 models.py)
   - Role: Immutable data structures for targets, spectra, and model components.
   - Key Specifications:
     * `Target`: Frozen dataclass (`target_id`, `redshift`, `sample`, `setup`,
       `pointing`, `ra`, `dec`).
     * `Spectrum1D`: Frozen dataclass (`wavelength`, `flux`, `uncertainty`,
       `mask`, `target`, `spectral_unit = u.AA`, `flux_unit = erg/(cm2 s AA)`,
       `flux_scale_factor`, `resolution_kms` array or scalar, `meta`, `history`).
       - Enforces identical 1D array shapes in `__post_init__`.
       - Implements `@classmethod Spectrum1D.read(filepath, target=..., config=...)`
         to support the v3.4 scriptable API (`ic.Spectrum1D.read(...)`).
       - `to_ndarrays()`: Returns float64 numpy arrays stripped of units in
         normalized O(1) space for LMFIT stability.
     * `EmissionLineDef`: Dataclass (`name`, `rest_wavelength`, `test_broad`,
       `ion_family`).
     * `LineComplex`: Dataclass (`lines`, `window_start`, `window_end`,
       `in_bounds: bool`, `primary_line: EmissionLineDef`).

3. ingest.py (Evolved from v3.3 ingest.py)
   - Role: Universal catalog registry and FITS spectrum unpacker.
   - Key Specifications:
     * `CatalogRegistry`: Reads CSV/FITS/ASCII target lists and normalizes column
       aliases (`id`/`gid`/`target_id`, `z`/`redshift`/`z_spec`).
     * `ObservationBuilder`:
       - Extracts 1D flattened arrays and units from FITS binary tables or
         primary HDUs.
       - Pre-scaled CGS protection: Prioritizes YAML scale factors (e.g.,
         `1e-20 erg / (cm2 s AA)`) when FITS `TUNIT` headers omit the scale
         prefix, and applies a safety guard if median extragalactic flux in CGS
         exceeds 1e-8 erg/(cm2 s AA).
       - Projects observed wavelengths to Vacuum Angstroms via `u.spectral()`.
       - Evaluates instrumental resolution sigma_inst(lambda_obs) at each pixel
         before de-redshifting so prism/grating resolution is preserved.
       - Cosmological de-redshifting: `wave_rest = wave_obs / (1 + z)`,
         `flux_rest = flux_obs * (1 + z)`, `err_rest = err_obs * (1 + z)`.
       - Dynamic O(1) scaling: Computes `scale_factor = 10**floor(log10(median))`
         and divides `flux_rest` and `err_rest` by `scale_factor` so LMFIT
         Jacobians never truncate on 1e-20 floats.

4. io.py (New module extracted from v3.3 main.py)
   - Role: Multi-Extension FITS (MEF) and survey catalog writer.
   - Key Specifications (Solves the 999-column FITS TFIELDS limit permanently):
     * Writes `icarus_fit_<target_id>.fits` with 3 standard HDUs:
       - `HDU 0 (PrimaryHDU)`: Pipeline provenance, timestamp, cosmology (`H0`,
         `OM0`), target demographics (`Z_SYS`, `LOG_MBH`, `MBH_ERR`, `MBH_CAL`,
         `LOG_LBOL`, `LAM_EDD`, `R_FEII`, `SFR_VAL`, `SFR_IND`, `BPT_N2HA`,
         `BPT_O3HB`), and the integer bitmask `CONF_FLG` (all keywords strictly
         <= 8 characters to prevent HIERARCH warnings).
       - `HDU 1 (BinTableHDU, EXTNAME='LINE_CATALOG')`: Long-format QTable with
         1 row per emission line (~50 rows) and ~24 columns (`LINE_NAME`,
         `REST_WAVE`, `COMPLEX`, `AMP_NARROW`, `AMP_NARROW_ERR16`,
         `AMP_NARROW_ERR84`, `V_OFFSET`, `SIGMA_V_OBS`, `SIGMA_V_INT`,
         `AMP_BROAD`, `AMP_BROAD_ERR16`, `AMP_BROAD_ERR84`, `V_OFFSET_BROAD`,
         `SIGMA_V_BROAD_INT`, `AMP_OUTFLOW`, `V_OFFSET_OUTFLOW`,
         `SIGMA_V_OUTFLOW`, `CONT_FLUX`, `EW_REST`, `SNR`, `IS_UPPER_LIMIT`,
         `COMPLEX_REDCHI`). All flux columns restored to true CGS units
         (`erg / (cm2 s)`) via `scale_factor`.
       - `HDU 2 (BinTableHDU, EXTNAME='SYNTH_SPEC')`: Full 1D rest-frame arrays
         (`WAVE_REST`, `FLUX_OBS`, `FLUX_ERR`, `MASK`, `CONT_POWERLAW`,
         `CONT_FEII`, `CONT_LOCAL`, `COMP_NARROW`, `COMP_BROAD`, `COMP_OUTFLOW`,
         `MODEL_TOTAL`, `NORM_PULL`) enabling full plot reconstruction offline.

5. exceptions.py (Retained from v3.3)
   - Role: Domain-specific exception hierarchy (`IcarusError`,
     `IcarusDataDimensionError`, `IcarusIngestionError`,
     `IcarusConfigurationError`, `IcarusKinematicError`,
     `IcarusConvergenceError`).

6. logger.py (Retained from v3.3)
   - Role: Dual-handler logging to `icarus_run.log` and stdout.

7. dev_tools.py (Retained from v3.3)
   - Role: `@dev_hook` decorator and `DevState` singleton supporting `.dev`
     directives (`PAUSE`, `WATCH`, `PERTURB`, `SYNTH_INJECT`, `BYPASS`,
     `FORCE_FAIL`, `PROFILE`, `TRACE_MEMORY`, `DUMP_DAG`).
